# Contributing

Contributions to the UI5 Geomap project are welcome!

This section explains our conventions, how to run the project locally, and how to run the documentation website.

For the full contribution policy — including the [SAP Open Source Code of Conduct](https://github.com/SAP/.github/blob/main/CODE_OF_CONDUCT.md), issue handling, and the Developer Certificate of Origin (DCO) — see the [CONTRIBUTING.md](https://github.com/UI5/webcomponents-geomap/blob/main/CONTRIBUTING.md) file in the repository.
