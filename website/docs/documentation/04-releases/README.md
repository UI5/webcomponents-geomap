# Releases

The page describes the release management process of UI5 Geomap.

## Release Strategy

UI5 Geomap follows the [npm semantic versioning strategy](https://docs.npmjs.com/about-semantic-versioning)
and produces the following type of releases:

- **Patch releases**

Includes backward-compatible bug fixes and increment the third digit, for example, 2.0.1.


- **Minor releases**

Include backward-compatible new features and increment the middle digit and reset the last digit to zero, for example, 2.1.0, 2.2.0, or 2.3.0.


- **Major releases**

Include changes that break backward compatibility and increment the first digit and reset the middle and last digits to zero, for example, 2.0.0.

The changelog of all releases can be found on the [GitHub Releases](https://github.com/UI5/webcomponents-geomap/releases) page.
