# First Steps

## Installation

Install the package from npm:

```bash
npm install @ui5/webcomponents-geomap
```

or with yarn:

```bash
yarn add @ui5/webcomponents-geomap
```

## Usage

Import the component and use the custom tag in your HTML:

```javascript
import "@ui5/webcomponents-geomap/dist/Geomap.js";
```

```html
<ui5-geomap></ui5-geomap>
```
