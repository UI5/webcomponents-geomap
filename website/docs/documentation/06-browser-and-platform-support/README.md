# Browser and Platform Support

UI5 Geomap is supported by all major modern browsers on the desktop and mobile platforms listed below.

UI5 Geomap renders maps with [MapLibre GL JS](https://maplibre.org/), which requires **WebGL2**. All of the browsers and platforms listed below support WebGL2; very old browsers without WebGL2 support are not supported.

## Desktop

| Platform                       | Google Chrome   | Microsoft Edge  | Mozilla Firefox | Mozilla Firefox ESR | Apple Safari    |
| ------------------------------ | --------------- | --------------- | --------------- | ------------------- | --------------- |
| **Windows** (versions 10 & 11) | Latest 2 Stable | Latest 2 Stable | Latest 2 Stable | Latest              | n/a             |
| **macOS** (Latest 2 versions)  | Latest 2 Stable | Latest 2 Stable | Latest 2 Stable | Latest              | Latest 2 Stable |
